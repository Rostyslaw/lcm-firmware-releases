# LCM firmware releases

This public repository is for **compiled LCM firmware binaries and release notes only**. The firmware source code is kept in a separate private repository.

Each release will contain a versioned `firmware.bin` for the ESP32 machine controller. The binary is publicly downloadable and can be analyzed. Do not upload source code, NVS data, Wi-Fi credentials, device settings, private keys, or build logs containing secrets.

No firmware release has been published yet.
